# Exercises 08: Terraform Security

Complete these alongside `modules/08-security`.

## Deliverables

1. Manually review intentionally insecure Terraform.
2. Compare your findings with Checkov or tfsec.
3. Create your own hardened remediation.
4. Run a tabletop response for a committed tfvars secret.

See `../../modules/08-security/exercises/README.md` for the full exercise
instructions.
